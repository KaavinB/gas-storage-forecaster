How it works

Pipeline

  1. Ingest EIA weekly storage, EIA Henry Hub spot and NOAA CPC degree days into PostgreSQL with idempotent upserts.
  2. Check 12 data-quality rules (freshness, gaps, ranges). A failure stops the run before anything is published.
  3. Forecast the next EIA report with models retrained daily on everything published so far.
  4. Alert by email when thresholds are crossed. Every alert is logged once, however often the job runs.
  5. Publish this page. GitHub Actions runs the whole chain every day.

Why it's trustworthy

  • Every feature uses only data public on the forecast date. A test scrambles all later data and checks that no feature changes.
  • Models are scored walk-forward against a naive 5-year-average baseline, with Diebold–Mariano and binomial significance tests.
  • Weather is NOAA's gas-home-weighted heating degree days against trailing 10-year normals.
  • The price-direction model shows no skill, and the page says so instead of hiding it.
