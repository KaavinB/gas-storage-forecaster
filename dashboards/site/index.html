Gas Storage Monitor

Source on GitHub

Weekly forecasts of US natural gas storage, made the day before each EIA report.

Gas in storage

Lower 48 working gas compared with the past five years, Bcf.

Method

The forecast is refreshed daily from EIA weekly storage, EIA Henry Hub spot prices, and NOAA heating and cooling degree days. Ridge regression and XGBoost predict how far the week will differ from the five-year average; XGBoost is the published forecast. Accuracy is measured on forecasts made the day before each Thursday release, using only data public at the time.

Forecast timing and look-ahead checks

On the Wednesday before a release the report week has already ended and its weather is known, but EIA has not yet published the storage figure. Every input has a publication rule: storage counts once released, degree days two days after the fact, and Henry Hub prices seven days after, because EIA posts them in weekly batches.

A test overwrites all data published after a forecast date with placeholder values and confirms the forecast inputs do not change. Models are retrained before every forecast and only learn from outcomes that had been published by then.

Pipeline and data checks

A GitHub Actions job runs daily at 16:37 UTC, after the Thursday release. It loads new data into PostgreSQL, runs 12 data checks for freshness, gaps and out-of-range values, retrains the models, sends alerts and rebuilds this page. If a data check fails, nothing is published. Loads are idempotent, so re-running a day changes nothing.

Limitations
  • The backtest uses current, revised EIA and NOAA data, not the values as first published.
  • EIA reclassifications between working and base gas are part of the weekly change. In the week ending June 11, 2021 the reported change was +16 Bcf against an implied flow of about +67 Bcf.
  • The models understate the most extreme cold weeks, when production freeze-offs add to demand. Production data is not used.
  • Henry Hub prices arrive about a week late from EIA, which limits any price model.
